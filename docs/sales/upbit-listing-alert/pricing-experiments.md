# 가격 실험안: 상장 알림 유료 티어 (결제 없이 수요 확인)

> 2026-10-08 · sales-marketer · 보드 T-011
> 전제: **결제는 열지 않는다.** 포워드 30건 + 중단 기준 미해당 + 법무 T-010 답변 수령, 세 조건이 모두 충족될 때까지. 이 문서의 실험은 전부 결제 없는 수요 측정이다.

## 1. 유료 티어 가설

무료 알림 본문은 계속 무료. 유료는 "더 빠른 신호"가 아니라 "더 깊은 맥락·기록"이다.

| # | 가설(유료 묶음) | 가격 가설(월) | 누구 | 반증 조건 |
|---|---|---|---|---|
| H1 | 월간 상장 이벤트 결산 리포트(PDF): 그 달 전 건 결과, 누적 포워드, 무기한 나이·거래대금 구간별 분포 | 9,900원 | 1차 타깃(현물 추격 매수 고민자) | 대기자 중 "이 가격이면 낸다" < 20% |
| H2 | H1 + 과거 이벤트 아카이브(전 건 표, 검색) + 알림마다 무기한 나이 구간별 분포 상세 | 19,900원 | 2차 타깃(해외 선물 쓰는 중급) | H2 선택 비율 < H1의 1/3 |
| H3 | 연간 결제(2개월 할인) | 99,000원/년 | 기존 무료 구독 6개월 이상 | 연간 선호 < 15% |
| H4 | 단건: "상장 이벤트 통계 리포트" 1회 구매 | 4,900원 | 구독이 부담인 사람 | 단건 선호가 구독보다 높으면 구독 모델 재검토 |

하지 않는 것: 실시간 숏 신호, 레버리지 안내, 수익 곡선 기반 티어, 거래소 레퍼럴 수익.

## 2. 결제 없는 수요 테스트

### 실험 A. 대기자 명단(waitlist)
- 위치: 무료 채널 월간 결산 글 끝 링크 1개, 고정 공지 맨 아래 1줄. 커뮤니티 글에는 넣지 않는다(홍보 규칙 회피 목적 아님, 신뢰 순서 때문).
- 도구: 구글 폼 또는 기존 데스크에 정적 폼 1장(신규 인프라 없음). 수집 항목은 텔레그램 아이디(선택)와 아래 설문만. 이메일·전화번호는 받지 않는다(개인정보 최소 수집, 법무 확인 전).
- 문구:
  ```text
  유료 버전을 만들지 고민 중입니다. 아직 결제는 없습니다.
  포워드 기록 30건이 쌓이고 결과가 과거와 크게 어긋나지 않을 때만 열고, 어긋나면 열지 않습니다.
  관심 있으면 남겨 주세요(1분).
  ```

### 실험 B. 설문(대기자 폼에 포함, 5문항)
1. 지금 알림을 어떻게 쓰나요? (추격 매수 전 확인 / 보유 코인 점검 / 해외 선물 참고 / 그냥 구경)
2. 무료 알림 외에 가장 필요한 것 1개 (월간 결산 / 과거 아카이브 / 구간별 분포 상세 / 필요 없음)
3. 가격 민감도 질문(Van Westendorp 4문항): 너무 싸서 의심되는 가격 / 적당한 가격 / 비싸지만 낼 가격 / 너무 비싼 가격 (원/월)
4. 결제 방식 선호 (월 / 연 / 단건)
5. 이 채널을 알게 된 경로 (커뮤니티 글 / 지인 / 유튜브·블로그 / 기타)

### 실험 C. 가짜 문 없이 가격 카드 A/B
- 월간 결산 글에 "유료 버전 구상"을 두 버전으로 번갈아 게시(홀수 달 H1 9,900원 / 짝수 달 H2 19,900원), 각 버전의 대기자 등록률 비교.
- 결제 버튼처럼 보이는 가짜 문(fake door)은 쓰지 않는다. "결제 없음, 관심 등록"이라고 명시한다(오인 유발 방지).

### 실험 D. 무료 샘플 리포트 반응
- M3, M6에 월간 결산 리포트 1회분을 무료로 전체 공개 → 조회수 ÷ 구독자, 대기자 전환율을 본다. H1의 가치 확인용.

## 3. 측정과 판단 기준 (M6 시점, 사전 고정)

| 지표 | 유료 실험 진행 | 보류 |
|---|---|---|
| 대기자 수 | ≥200 | <80 |
| 대기자 ÷ 구독자 | ≥10% | <5% |
| 설문 "적당한 가격" 중앙값 | ≥9,900원 | <5,000원 |
| 무료 구독 30일 잔존율 | ≥70% | <50% |
| 포워드 기록 중단 기준 | 미해당 | 해당 → **수요와 무관하게 중단** |

- 진행 판정이어도 결제는 법무 답변 이후. 그 전까지는 대기자에게 "아직 결제 없음" 상태만 공유한다.
- 보류 판정이면 유료 티어 대신 교육 콘텐츠(포트폴리오 2순위)·리서치 프로세스 판매(4순위) 수요 조사로 넘긴다.

## 4. 열린 질문 (팀장·법무)
- 대기자 폼에서 텔레그램 아이디를 받는 것 자체가 개인정보 처리방침을 요구하는가 → 법무 T-010 범위로 넘김(답 전에는 아이디도 선택 항목, 익명 응답 허용).
- 유료 티어가 "실시간 코인별 정보 유료 제공"으로 묶이면 유사투자자문 판단이 달라지는가 → H1(비실시간 월간 리포트)을 첫 유료 후보로 둔 이유.
