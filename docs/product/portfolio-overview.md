## 현재 엣지 상태 (한 줄씩)
- 업비트 상장 후 7일 하락: **신호 PASS-WITH-CAVEATS**, 자동 숏 상품 VETO(1배 MDD −72%, 2·3배 파산; OOS 2023-07~2026-09, 왕복 0.4%·펀딩 포함).
- SMA200 필터: **BTC·ETH 낙폭 축소 오버레이로만 PASS-WITH-CAVEATS**. 수익 우위 VETO(USD 거래소 B&H 대비 1.16배, 9년 중 6년 열세; Upbit KRW-BTC 2018-04~2026-10 편도 0.05% 기준 MDD −54.7% vs B&H −74.1%).
- Policy C(라이브 CORE): **VETO — 판매 금지**.
- 펀딩 캐리·김프 페이드·크로스섹션 모멘텀: KILL. 펀딩 음수 합의: INCONCLUSIVE(20건). → 상품 재료 아님.
- **수익을 내세울 수 있는 "신호 판매" 상품은 현재 없다.** 포워드·실거래 기록도 없다.

## 추천: 업비트 상장 이벤트 알림을 "무료 공개 채널"로 먼저 시작
이유:
1. 반증을 버틴 유일한 비-OHLCV 신호이고, 구조적 이유(상장 펌프 후 되돌림)가 있다.
2. 레드팀이 "정직하게 팔 수 있다"고 명시한 형태(분포 그대로의 정보)와 상품 형태가 일치한다. 매매 지시가 없다.
3. 무료 채널이 곧 **공개 포워드 기록**이 된다. 유료화 전 증거를 쌓는 장치와 마케팅 채널이 같다.
4. 이미 있는 것으로 거의 다 만든다: `scripts/data/`의 공지·매핑·펀딩 수집기, `bot/telegram_notify.py`.

위험: 2025~26 상장 러시에 표본 79%가 몰려 있다. 상장 빈도가 줄면 상품 가치도 줄어든다. 포워드 결과가 나쁘면 유료화하지 않는다.

## 출시 전 필요조건 (공통)
1. **포워드 공개 기록**: 최소 3개월 또는 30건(상장 알림 기준) 중 늦은 쪽(월 약 5건이라 실제로는 약 6개월). 발송 시각이 남는 append-only 기록(텔레그램 채널 + 공개 저장소/웹 페이지). 결과(7일 뒤)도 자동 기입. 누락·오류도 숨기지 않고 기록.
2. **중단 기준 사전 고정**: 포워드 30건 하락 비율 < 50% 또는 알트 지수 대비 초과가 0 이하이면 유료화 중단, 리서치로 반환.
3. **고지 문구(모든 메시지·페이지)**: 투자 권유 아님 / 과거 분포이며 개별 결과를 예측하지 않음 / 원금 손실 가능 / 레버리지 숏은 과거 기간에 파산 사례 있음 / 성과는 기간·수수료·낙폭과 함께만 표기.
4. 법무 검토 답변 수령 전 유료 결제 열지 않음.
5. 라이브 CORE(Policy C) 결정(T-007)은 상품과 별개지만, 공개 실적 페이지에 Policy C 곡선을 상품 증거처럼 노출하지 않는다.

## 후속 팀 브리프

### 판매팀
- 채널: 무료 텔레그램 채널(1순위), 국내 코인 커뮤니티 통계 글, 유튜브/블로그 교육 콘텐츠(2순위 상품과 공유), SMA200 성적표 PDF(리드 마그넷).
- 메시지: "추격 매수 전에 보는 상장 이벤트 사실·과거 분포." "우리는 160개 전략을 버렸고 그 기록을 공개한다." 신뢰 = 실패 공개.
- 가격 가설(검증 대상): 상장 알림 유료 티어 월 9,900~19,900원(포워드 기록 공개 후) / 봇 키트 일회성 또는 연 구독 — 2단계에서 수요 조사 후 결정 / 교육 무료 콘텐츠 + 유료 강의는 수요 확인 후.
- 금지: 수익 보장, 승률 단독 표기, "+2040%"·"PF 4.48" 등 헤드라인, 레버리지 권유.

### 법무팀 (판단은 법무팀·전문가 몫 — 아래는 질문 목록)
1. 유사투자자문업(자본시장법) 신고 필요 여부를 형태별로: (a) 실시간 코인별 알림(무료/유료), (b) 비실시간 월간 리포트, (c) 셀프호스팅 소프트웨어 판매, (d) 교육 강의. 가상자산이 금융투자상품이 아닌 점이 판단에 어떻게 작용하는가?
2. 가상자산이용자보호법 등 가상자산 관련 법령이 정보 제공 상품에 적용되는 범위(불공정거래·시세 영향 우려 포함 — 다수 구독자가 같은 코인 정보를 동시에 받는 구조).
3. 이용약관·면책·환불 규정, 고지 문구 표준안, 해외 구독자 처리.
4. 데이터 재배포: 업비트 공지(비공식 API), 업비트 시세, Binance·Bybit·Bitget 시세·펀딩을 가공해 유료 제공할 때 각 거래소 이용약관·API 약관 위반 여부와 출처 표기 의무.
5. 봇 키트: 사용자가 자기 API 키로 실거래할 때 판매자 책임 범위, 오픈소스 라이선스(Freqtrade GPL 등) 의무.
