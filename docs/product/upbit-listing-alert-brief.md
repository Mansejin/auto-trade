# 상품 브리프: 업비트 원화 신규상장 이벤트 알림·리포트

> 2026-10-08 · product-strategist · 보드 T-006 · 투자 조언 아님
> 근거: `docs/research/redteam/upbit-listing-fade.md`(신호 PASS-WITH-CAVEATS, 자동 숏 상품 VETO), `docs/research/results/upbit-listing-fade.md`, 카드 `docs/research/cards/upbit-listing-fade.md`

## 1. 한 줄 가치 제안
업비트가 원화 상장을 공지하면, 그 코인의 해외 무기한 선물 현황(있는지, 유동성, 펀딩)과 과거 비슷한 상장 133건이 이후 7일간 어떻게 움직였는지를 분포 그대로 정리해 알려 준다.

"숏 신호"가 아니라 **"추격 매수 전에 볼 사실과 과거 분포"**다. 매매 지시, 진입가, 목표가는 주지 않는다.

## 2. 증거와 한계

### 말할 수 있는 것 (모든 수치: OOS 상장일 2023-07~2026-09, Binance USDT-M 무기한 1배 숏 기준, 왕복 비용 0.4%·펀딩 포함)
| 항목 | 값 |
|---|---|
| 표본 | 133건(상장 시점에 해외 무기한이 이미 있던 KRW 상장) |
| 상장 다음 날 ~ 7일 뒤 가격이 비용·펀딩을 넘어 하락한 비율 | 63.9%(약 3건 중 2건) |
| 같은 7일 알트 지수 대비 평균 초과 하락 | −4.15%p/건, 무작위 비교 1,000회 대비 100백분위 |
| 보유 7일 중 고가 기준 +30% 이상 상승한 경우 | 19건(약 7건 중 1건). 최대 +201% |
| 숏을 실제로 굴렸을 때(1배, 현실 사이징) | **MDD −71.8%, 최악의 달 −62.7%(2026-01)**. 2배·3배는 기간 안에 파산 |
| 진입 시점 민감도 | 공지+24h 진입 PF 1.93, D+2 1.72, D+3 1.77 — 특정 시각에 의존하지 않음 |

### 한계 (리포트에도 그대로 적는다)
- OOS 133건 중 79%가 2025~26년 상장 러시 구간이다. 상장 빈도·펌프 크기가 줄면 분포도 바뀔 수 있다.
- 원장 전체 약 165개 시도 기준 다중검정 문턱(t≈3.4)에 못 미친다(t=2.74).
- 상폐된 무기한 5건·날짜 모호 2건 등 데이터 결함 7건(제거하면 결과가 좋아지는 방향).
- **포워드(실시간) 기록은 아직 없다.** 실거래 기록도 없다.
- 사용 금지: "상장 직후 무기한이 생기면 PF 4.48"이라는 관찰은 카드 밖 사후 관찰이다. 상품 문구·리포트에 쓰지 않는다.

## 3. 상품 형태 비교
| 형태 | 증거와 맞나 | 판단 |
|---|---|---|
| 신호 구독(숏 진입 알림) | 아니다. 1배도 MDD −72%, 레버리지 파산 | **판매 불가** |
| 자동매매 숏 봇·키트 | 아니다. 레드팀 VETO | **판매 불가** |
| TradingView 초대 스크립트 | 이벤트가 공지 기반이라 차트 지표로 구현이 어색 | 보류 |
| **이벤트 알림 + 1페이지 리포트(텔레그램)** | 예. 분포·사실 정보 | **채택** |
| 월간 상장 이벤트 결산 리포트 | 예. 공개 포워드 기록과 같은 형태 | 유료 티어 후보 |
| 교육(상장 펌프의 통계) | 예 | 콘텐츠 마케팅 겸용 |

### 알림 1건의 내용(MVP)
1. 공지 제목·시각(KST), 원문 링크
2. 해외 무기한 존재 여부(Binance/Bybit/Bitget), 무기한 상장 후 경과일, 24h 거래대금, 현재 펀딩
3. 과거 분포: 7일 후 수익률 분위수(10/50/90%), +30% 이상 역행 비율, 무기한 나이 구간별 표본 수
4. 고정 고지: "과거 분포이며 이 코인의 결과를 예측하지 않습니다. 약 7건 중 1건은 7일 안에 +30% 이상 올랐습니다."
5. 해외 무기한이 없으면 "과거 표본에 해당하지 않음"이라고만 쓴다.

## 4. 타깃과 가격 가설
- 1차: 업비트 원화 시장 개인 투자자 중 상장 공지 직후 추격 매수를 고민하는 사람(정보 = 리스크 체크).
- 2차: 해외 선물을 쓰는 중급 트레이더(펀딩·유동성 정보를 빠르게 보고 싶은 사람).
- 이벤트 빈도: 2025년 62건, 2026년 1~9월 43건 → 월 약 5건(무기한 있는 건 기준).
- 가격 가설(검증 대상, 확정 아님): 무료 = 알림 본문 / 유료 월 9,900~19,900원 = 분위수 상세·월간 결산·과거 이벤트 아카이브. 유료는 포워드 기록 공개 이후에만.

## 5. 출시 전 필요조건
1. **포워드 공개 기록**: 무료 채널에서 최소 3개월 또는 30건 중 늦은 쪽까지(월 약 5건이라 실제로는 약 6개월), 알림마다 발송 시각이 남는 공개 로그(텔레그램 채널 + 저장소/웹의 append-only 기록). 7일 뒤 결과를 같은 스레드에 자동 기입.
2. 포워드 결과가 과거 분포와 크게 어긋나면(예: 30건 하락 비율 < 50%) 유료 전환을 멈추고 리서치에 되돌린다. 기준은 출시 전에 고정한다.
3. 고지 문구: 투자 권유 아님, 과거 분포, 손실 가능, 레버리지 숏의 파산 사례(2·3배) 명시.
4. 법무 검토 완료(아래 질문).

## 6. 후속 팀 브리프

### 판매팀
- 채널: 무료 텔레그램 채널(포워드 기록 겸), 국내 코인 커뮤니티의 "상장 펌프 통계" 글, 유튜브 쇼츠/블로그(교육형).
- 메시지: "상장 공지 뒤 1주일, 과거 133건은 이렇게 움직였다 — 추격 매수 전 확인용." 수익률·승률 헤드라인 금지. "숏 치면 번다"류 문구 금지.
- 쓰면 안 되는 표현: 수익 보장, "64% 확률로 떨어진다"(분포 설명 없이), 레버리지 권유, PF 4.48 관찰.

### 법무팀 (판단은 법무팀·전문가 몫, 아래는 질문)
1. 특정 코인의 과거 분포를 공지 직후 유료로 보내는 알림이 유사투자자문업(자본시장법) 신고 대상인가? 가상자산이 금융투자상품이 아닌 경우에도 해당되는가, 가상자산이용자보호법 등 다른 규제가 걸리는가?
2. 무료 채널 / 유료 구독 / 월간 리포트(비실시간) 각각 판단이 달라지는가?
3. "매매 지시 없음, 분포만 제공" 형식이 규제 판단에 영향을 주는가?
4. 업비트 공지(비공식 API로 수집)와 Binance·Bybit 시세·펀딩 데이터를 가공해 유료로 재배포하는 것이 각 거래소 이용약관·API 약관에 걸리는가?
5. 필수 고지·약관·환불 규정, 해외 거주 구독자 처리.

### 앱개발팀 (최소 기능)
- 재사용: `scripts/data/fetch_upbit_announcements.py`(공지 파싱), `scripts/data/build_listing_perp_map.py`(상장↔무기한 매핑), `scripts/data/fetch_funding.py`, `scripts/data/fetch_binance_klines.py`, 과거 분포는 `scripts/bt_upbit_listing_fade.py` 산출물 `reports/research-cards/upbit-listing-fade.json`에서 고정값으로 읽는다(실시간 재학습 없음).
- 발송: 기존 `bot/telegram_notify.py`의 `send()` 재사용.
- MVP: (1) 공지 폴링(1~5분) → (2) 티커의 무기한 존재·거래대금·펀딩 조회 → (3) 템플릿 메시지 발송 → (4) 7일 뒤 결과 자동 회신 → (5) append-only 기록(CSV/JSON, 발송 시각 포함).
- 하지 않을 것: 주문 기능, 숏 자동매매, 대시보드 확장(포워드 기록 페이지 1장만).
- 주의: 업비트 공지 API는 비공식이라 끊길 수 있음 → 실패 시 알림 누락을 로그로 남기고 공개 기록에도 "누락"으로 표기.
