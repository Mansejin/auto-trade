## 0. 결론 먼저
- **"SMA200 신호"를 단독 유료 구독으로 파는 것은 권하지 않는다.** 공짜 대체재가 완전하고, 메시지가 연 6~7번뿐이며, 포워드 기록이 0일이고, 수익 우위 주장은 레드팀이 막았다.
- **팔 수 있는 것은 신호가 아니라 "기록과 해설"이다.** 추천 경로: 무료 일일 상태 기록(공개 포워드 로그) → 6개월 뒤 상장 알림 채널 유료 티어에 **월간 "BTC 레짐 리포트"**를 묶음 → 병행으로 교육 콘텐츠.
- **봇 키트·호스팅 자동매매는 보류.** 금융위·FIU 유권해석이 "거래소 API로 고객 계좌에 자동매매를 해 주는 소프트웨어 개발·공급"을 특정금융정보법상 가상자산사업자(VASP) 신고 대상일 **소지**가 있다고 봤다(아래 2절). 변호사 답변 전 착수 금지.
- **남의 돈 운용은 하지 않는다.** 선택지가 아니다.

## 1. 왜 "유료 신호"는 약한가
| 약점 | 사실 |
|---|---|
| 공짜 대체재 | TradingView·업비트·바이낸스 차트 어디서나 MA(200) 지표 1개로 같은 선을 무료로 본다. TradingView 알림 기능으로 "종가가 SMA200 위/아래" 알림도 직접 건다. 규칙은 수십 년 된 공개 지식이다. |
| 메시지가 적다 | 8.5년 동안 전환 55회(연 약 6.5회). 구독자는 한 달에 0~1번 "바뀌었다" 메시지를 받는다. 월 구독료 대비 체감 가치가 낮고, 한 번 규칙을 알면 해지 사유가 생긴다. |
| 수익 우위 증거 없음 | USD 거래소 기준 B&H 대비 1.16배, 시작일을 바꾸면 B&H 미만, 9년 중 6년 B&H 열세. 횡보장 휩쏘 연 −9~−15%. "돈을 더 번다"고 말할 수 없다. |
| 낙폭 개선도 절반은 착시 | 낙폭 축소 대부분은 평균 노출 53% 효과. 같은 노출 고정 보유가 MDD가 더 얕다(−49.2% vs −54.7%). 빠른 폭락(2021년 −53%)은 못 막는다. |
| 포워드 기록 0 | 라이브 시작 2026-10-08, 실체결 없음. 백테스트만으로 받는 구독료는 신뢰도 문제를 만든다. 전환이 드물어 1년 포워드도 "규칙대로 보냈다"는 증명일 뿐 성과 증명은 아니다. |

**정직한 가치 제안(쓸 수 있는 유일한 형태):** "BTC·ETH 장기 보유자가 큰 약세장에서 규칙대로 현금으로 물러나도록 돕는 공개 규칙과, 그 규칙을 매일 지켰다는 공개 기록. 수익이 더 높다는 증거는 없다."

## 3. 추천 경로와 순서

**추천: (e) 월간 BTC 레짐 리포트를 상장 알림 채널 유료 티어에 묶고, 그 전 6개월은 무료 공개 기록으로 증거를 쌓는다. (f)는 유입 채널로 병행.**

이유:
1. 고객이 돈을 내는 이유가 "공짜로 볼 수 있는 선"이 아니라 **매일 지켜진 공개 기록 + 한계까지 쓴 월간 해설**이다. 대체재가 없는 부분은 이것뿐이다.
2. 비실시간·방송형이라 쟁점 메모의 위험 감소 설계(단방향, 지시어 없음, 속도 차등 없음)를 그대로 따른다. 주문 실행이 없어 VASP·투자일임 쟁점을 피한다.
3. 상장 알림 유료 티어(월 9,900~19,900원 가설)에 얹으면 단독 상품의 "연 6번 메시지" 약점이 사라진다. 이미 있는 채널·NAS·w1 봇으로 거의 다 만든다.

## 4. 필요한 포워드 기록

현재: w1이 SMA200 규칙으로 라이브지만 **Upbit KRW 잔고 ≈ 0 → 주문이 나가도 실체결이 없다.** 지금 상태로는 "실거래 기록"이라고 부를 수 없다. 봇에는 거래 목록(state)만 있고 **일일 판정 로그는 없다**(확인: `bot/` 내 일일 신호 append-only 기록 부재).

권고(둘 다, 우선순위 순):
1. **신호 전용 공개 기록(필수, 비용 0)**: 매일 일봉 확정 후 1줄 append-only — 날짜(KST 09:00 기준 확정 봉), 종가, SMA200, 판정(보유/현금), 전환 여부, 기록 시각, 데이터 출처. 사후 수정 금지, 오류는 정정 줄을 추가. 공개 위치는 정적 파일/데스크 페이지 1개. 이 기록이 판매 증거의 본체다.
2. **소액 실자금(권장)**: Upbit에 소액(예: 30만~50만원, 운영자가 결정)을 넣어 실체결·슬리피지·수수료를 남긴다. 목적은 수익이 아니라 "규칙대로 실제 주문이 나갔다"는 증빙. 금액은 공개하되 수익률 광고에 쓰지 않는다. 자금 투입 여부는 **사용자 결정**(보드 to: user).
- 표기 원칙: 포워드 성과는 항상 기간·전환 횟수·수수료·MDD·같은 기간 B&H와 함께. 6개월이면 전환 0~5회 수준이라 **성과 판단 불가**라고 리포트에 명시.
- 백테스트 수치 인용 시 Upbit 단독 금지, USD 거래소(Bitstamp/Binance) 수치 병기.

## 5. 중단 기준 (사전 고정)
1. **법무**: 변호사가 (e)를 유사투자자문업 신고 대상으로 보면 → 신고 후 개시 또는 무료 유지(비용 비교 후 사용자 결정). 데이터 약관상 유료 사용 불가 답변이면 → 라이선스 데이터 확보 전까지 유료 금지.
2. **운영 무결성**: 무료 기간 중 일일 기록 누락이 월 2일 초과이거나 사후 수정이 1건이라도 발견되면 → 유료 단계 진입 연기, 원인 수정 후 기록 6개월 재시작.
3. **수요**: 단계 1 종료 시 레짐 리포트 대기자 < 50명 또는 상장 알림 유료 티어 자체가 보류되면 → 레짐 리포트 유료화 중단, 무료 리드 마그넷으로 유지.
4. **규칙 이탈**: 포워드 MDD가 −60%(백테스트 최악 −55.6%보다 깊음)를 넘거나 레드팀이 판정을 VETO로 바꾸면 → 리포트 판매 중단, 리서치로 반환. 단기 수익 부진 자체는 중단 사유가 아니다(9년 중 6년 열세가 원래 특성).
5. 봇 키트·SaaS는 VASP 쟁점 답변 전 착수 금지. 타인 자금 운용은 어떤 경우에도 하지 않는다.

### 앱개발팀 (MVP — 주문 기능 추가 없음)
1. w1 일일 판정 append-only 로그: `logs/sma200-daily.jsonl`(가칭) — 필드: `date, close, sma200, state, switched, recorded_at, source`. 일봉 **확정 후** 1회만 기록(진행 중 봉으로 판정하지 않는지 확인 필요 — `bot/main.py` 판정 시점 점검). 재시작 시 같은 날짜 중복 기록 금지.
2. 공개 페이지 1개: 데스크에 읽기 전용 표(최근 90일 + 전환 목록) 또는 정적 파일. 신규 대시보드 기능 확장 금지.
3. 전환 시에만 채널 메시지 1건(`bot/telegram_notify.py` 재사용). 상장 알림 채널(@listing7d_kr) 정체성과 섞이지 않도록 **별도 무료 채널 또는 주 1회 요약**으로 할지 판매팀 결정.
4. 월간 리포트 초안 자동 생성 스크립트(로그 → 표 + 고정 고지문). 사람 검수 후 발송.
