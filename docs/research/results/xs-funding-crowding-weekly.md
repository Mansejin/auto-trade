카드: `docs/research/cards/xs-funding-crowding-weekly.md` (frozen 2026-10-08) · 데이터: T-038 · 보드: T-039 · 코드: `scripts/bt_xs_funding_crowding.py` · 원본 JSON: `reports/research-cards/xs-funding-crowding-weekly.json` · 실행 2026-10-10

## 판정: **KILL** (주 판정 = Binance USDT-M 무기한 유니버스)

사전 기각 기준 7개 중 3개 실패: OOS PF(x2) 1.002 < 1.1, 무작위(날짜 묶음) 81.7백분위 < 95(카드)·99(보드), OOS Sharpe 0.00 < BTC B&H 0.94. OOS 평균은 주 +0.005%로 사실상 0. 역모멘텀 비교(핵심 KILL 테스트)는 통과했지만 살릴 근거가 못 된다. 레드팀 불필요.

## 결과 보기 전에 고정한 구현 결정 (T-039, 팀장 지시 원문)

1. Universe: underlying_type COIN or blank only (exclude TRADIFI_PERPETUAL); BTC/ETH/stables excluded per card.
2. Backtest starts at the first weekly rebalance where >= 30 symbols pass the card's universe filters (listed >=30 days, top-30 by trailing 30d quote volume); earlier weeks are skipped, not partially filled. Report that start date.
3. Re-listed tickers: the '>=30 days listed' count restarts at the re-listing date; never compute returns across a tradable=0 gap.
4. 1000XXX vs XXX duplicates: if both are in the same week's universe, keep only the higher trailing-volume one.
5. If a held symbol stops being tradable mid-week, exit at its last tradable close.
6. Random-entry threshold is the 99th percentile (raised from the card's 95th per board principle, ~175 strategies tried); report both 95 and 99. Also run a date-clustered random test (same rebalance dates, random 5L/5S from the same universe) per prior cards. Keep the card's anti-momentum comparison (core kill test), OOS split, fee stress (2x), funding included.

인코딩 세부(같이 결과 전에 고정, 코드 docstring과 같음):
- 1의 제외 목록: BTCUSDT, ETHUSDT, USDCUSDT + 금 페그 PAXGUSDT, XAUTUSDT(가격 고정 자산). USTC 같은 디페그 코인은 알트로 남김.
- 2의 "통과" = 상장 30일 + 같은 주 중복 제거 후 적격 심볼 수. 스캔 시작 2020-06-01(카드 train 시작).
- 3: "상장 30일" = t 직전 연속 tradable 30일. 0거래량·빈 날이 하나라도 끼면 다시 센다.
- 4: 1000000/1000/1M 접두를 떼고 같은 이름이면 30일 거래대금 큰 쪽만 남기고, 그다음 상위 30을 뽑는다(19건 제거).
- 5 + 카드 상폐 규칙: 청산 시가 전에 거래가 끊기면 마지막 tradable 종가가 청산 시각이고, 가격 손익은 카드대로 숏 0·롱 −50%. 실제 종가 버전은 참고로 따로 보고.
- 신호 = [t−7일, t) 정산 펀딩 합 ÷ 7(일 환산이라 1h/4h/8h 정산 심볼을 같은 잣대로 비교). 동률은 심볼명.
- 보유 펀딩 = (t, 청산] 정산분, 고정 수량(정산일 시가/진입가). 롱 지급·숏 수취.
- 1배 숏은 보유 중 일봉 고가 ≥ 진입가 2배면 −100%(펀딩 무시).
- 자본은 두 다리에 반씩, 각 1배: 주간 수익 = (롱 평균 + 숏 평균) / 2.
- 비용 편도: x2 = 수수료 0.12% + 슬리피지 0.20% = 0.32%(판정), base = 0.06% + 0.20% = 0.26%. 들어가고 나가는 다리에만 부과(유지 다리 비중 조정 비용 무시). 매주 전부 교체 버전도 보고.
- 분할(리밸런스 날짜): train < 2023-07-01 ≤ OOS.
- 판정 규칙: 카드 기준 하나라도 실패 → KILL. 전부 통과 + 날짜 묶음 무작위 ≥ 99 → SURVIVE. 전부 통과인데 95~99 → PARTIAL.

## 해석

- 엣지는 train(2020~2023)과 OOS 앞 절반(~2025-02)에만 있었고, 2025년부터 꺼졌다(OOS 뒤 절반 PF 0.67).
- 펀딩 캐리는 크지만 가격 손익이 그만큼 되가져간다. 음수 펀딩 = 숏이 몰린 코인은 계속 빠졌다. "쏠린 쪽 반대편에 서서 이자를 받는다"는 이야기는 OOS에서 이자만큼 가격으로 잃는 구조였다.
- 2025년 이후 숏 다리는 소형 밈 알트 스퀴즈(1배 청산 23건)에 노출된다. 판매·운영 상품으로 쓰기 어렵다.
- 시장 중립 Sharpe 0.00이라 BTC B&H(0.94)·SMA200(0.97) 대비 쓸 이유가 없다.
