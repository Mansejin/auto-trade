## 체결 모델 (둘 다 같은 신호)
**A. 테이커**: 신호봉 t → **t+1 시가** 매수(+2bps 슬리피지), 테이커 0.06%/편도.  
- 손절: 봉 k(≥t+1)에서 `low ≤ 손절가` → `min(open[k], 손절가)` − 2bps, 테이커.  
- 익절: `high ≥ 익절가` → 익절가 − 2bps, 테이커. 같은 봉에 둘 다면 손절 먼저.  
- 청산 신호: 봉 s 마감 → s+1 시가 − 2bps, 테이커.

**B. 메이커** (N = **1봉**으로 고정. 이 전략의 보유가 1봉이라 더 길게 기다리면 다른 거래가 된다):  
- 진입: 신호봉 t 종가 L에 매수 지정가. **t+1 봉에서 `low < L`(관통)일 때만** L에 체결, 메이커 0.02%. 아니면 신호 버림(닿기만 하면 미체결).  
- 손절: 테이커 시장가(A와 같은 식, 0.06% + 2bps). 체결봉 안에서도 `low ≤ 손절가`면 손절된 것으로 본다(보수).  
- 익절: 체결 직후 +2.0%에 매도 지정가 상주. **체결봉 다음 봉부터** `high > 익절가`일 때 익절가에 메이커 체결.  
- 청산 신호: 봉 s 마감 → s 종가 X에 매도 지정가. **s+1 봉에서 `high > X`**면 X에 메이커 체결. 아니면 **s+2 봉 시가에 테이커**(0.06% + 2bps)로 정리.  
- 한 봉 안 순서(보수): 손절 → 청산 지정가 → 익절.  
- 슬리피지: 메이커 체결은 0, 테이커 체결은 2bps/편도.

**비용 스트레스(판정 기준) = 2배**: 테이커 0.12% + 4bps/편도, 메이커 0.04%/편도.  
펀딩: 보유가 대부분 5~10분이라 무시한다(정산 시각을 걸치는 거래는 드묾). 결과에 걸친 건수를 적는다.

## 기각 기준 (사전, 하나라도 걸리면 KILL; 판정은 B, 2배 비용)
1. B OOS PF(2x) **< 1.1** → KILL.
2. B OOS 체결 거래 **< 150** → INCONCLUSIVE(다른 기준이 KILL이면 KILL).
3. 무작위 진입 1,000회: 실제 B 신호마다 OOS에서 **같은 구름 상태**(신호봉 종가가 26봉 전 두 선행스팬 아래인지)의 봉을 무작위로 뽑아 **같은 B 체결 모델·같은 청산 규칙·2x 비용**으로 돌림. 통계 = 체결 거래당 평균 순수익. 실제 B가 **99백분위 미만** → KILL. (best-of 선택 + 원장 ~165장 시도를 반영해 95→99로 올림)
4. **B가 A를 이겨야 한다**: OOS 2x 비용에서 B의 PF와 합계 순수익(Σr)이 둘 다 A보다 커야 한다. 아니면 KILL.
5. 앞·뒤 절반 B PF(2x) 중 하나라도 **< 1.0** → KILL.
6. 종목 전이: ETHUSDT에 그대로 → B OOS PF(2x) **< 1.0** → KILL.
7. 보고(판정 아님, 단 해석에 반영): 진입 체결률, 청산 지정가 체결률, **역선택** — B 신호 전체에 대해 A식 반사실 수익(t+1 시가 진입, A 청산, 비용 전)을 계산해 체결된 신호 vs 미체결 신호의 평균을 비교. 체결된 쪽이 체계적으로 나쁘면 그렇게 적는다. BTC B&H(같은 OOS) 수익도 적는다.
