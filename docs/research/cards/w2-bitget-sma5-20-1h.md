# 카드: w2-bitget-sma5-20-1h (w2 Bitget 봇 현행 SMA5/20 교차, 1h)

우물: 모멘텀·추세 (OHLCV 지표) · 상태: frozen 2026-10-10 · 보드 T-033  
목적: w2 Bitget 봇을 LIVE로 올리기 전 반증. **현행 설정을 그대로 고정**한다(튜닝 없음). 이 카드는 데이터를 받기 전, 백테스트를 돌리기 전에 썼다.

## 한 줄 원칙
BTC 1시간봉에서 SMA5가 SMA20을 위로 뚫으면 롱, 아래로 뚫으면 청산한다(손절 3%, 익절 6%).

## 왜 돈이 나오나 (주장)
- 추세 추종: 짧은 평균이 긴 평균을 넘는 건 단기 모멘텀 시작이고, 1h 모멘텀이 이어지면 교차 뒤 상승분을 먹는다.
- 솔직한 사전 평가: 구조적 이유(누가 왜 손해 보는지)가 없는 순수 가격 지표 규칙이다. 원장 기준으로 **이미 판 우물**(5번 "bull 슬리브 대체 … SMA", 교훈 "always-on은 B&H를 못 이긴다")에 속한다. KRW-BTC 4h SMA·SMA10-50은 KILL, 1d SMA5/20은 판정 없이 교체됐다. 사전 기대는 KILL이고, 이 카드는 LIVE 전에 그걸 확인하는 절차다.

## 고정 값 (`strategies/bitget_btc_usdt_sma.json`, `bot/signals.py`, `bot/bitget_runner.py` 그대로)
| 항목 | 값 |
|---|---|
| 종목·시장 | Bitget BTCUSDT USDT-M 무기한, 롱만, one-way |
| 봉 | 1h, **마감된 봉**만 평가 (`close[-2]`) |
| 지표 | SMA(종가, 5), SMA(종가, 20) 단순 이동평균 |
| 진입 | 마감봉 i에서 `SMA5[i-1] <= SMA20[i-1]` 이고 `SMA5[i] > SMA20[i]` (cross_above), 포지션 없을 때 |
| 청산(신호) | 마감봉 i에서 `SMA5[i-1] >= SMA20[i-1]` 이고 `SMA5[i] < SMA20[i]` (cross_below) |
| 손절·익절 | 기준가 = 봇이 기록한 진입가 = **신호봉 종가**. 마감봉 종가가 기준가 대비 ≤ −3% → 손절, ≥ +6% → 익절. 봉 안(고가·저가) 체크 없음. 손절·익절을 교차 청산보다 먼저 본다 |
| 재진입 | 손절·익절 뒤에는 다음 cross_above가 새로 나올 때만 |
| 크기 | 가용 USDT × `ORDER_FRACTION` 명목, 레버리지 1배로 본다(거래별 수익률을 순차 복리) |

하이퍼 3개(SMA 5, SMA 20, SL3/TP6 한 쌍)는 현행 값이고 바꾸지 않는다.

## 체결 가정 (보수적)
- 신호는 봉 i 마감 뒤에만 안다 → 체결은 **봉 i+1 시가**(봇은 `POLL_SECONDS`=300초 이내 시장가). 손절·익절·교차 청산도 같은 방식으로 다음 봉 시가.
- 수수료: 기본 Bitget 테이커 **0.06%/편도**. 스트레스 = **0.12%/편도 + 슬리피지 5bps/편도**. 판정은 스트레스 기준.
- 펀딩: 보유 중 정산(진입 < t ≤ 청산) 마다 롱이 rate를 낸다. Bitget 이력 대용으로 Binance BTCUSDT 펀딩.
- 공유 계정: w2는 같은 Bitget 계정의 w5(freqtrade BTC 숏)가 포지션을 들고 있으면 진입을 건너뛴다. **모델링하지 않는다**(w5 이력 없음). 실제 거래 수는 백테스트보다 적고, 건너뛴 거래가 무작위가 아니라 약세 구간에 몰릴 수 있다는 점만 적는다.

## 기각 기준 (사전, 판정은 스트레스 비용 기준)
- 분할: train 2019-09~2023-06 / **OOS 2023-07~2026-09** 고정. 전체 기간 앞·뒤 절반도 보고.
1. OOS 수수료 2배 + 슬리피지 + 펀딩 후 **PF < 1.1 → KILL**.
2. OOS 거래당 평균 ≤ 0 → KILL.
3. 전체 거래 < 30회 → INCONCLUSIVE.
4. 무작위 진입 1,000회: OOS에서 같은 거래 수·같은 보유 시간(봉 수)으로 무작위 시각에 롱 → OOS 평균이 **95백분위 미만이면 KILL**.
5. BTC B&H 대비(노출 기준): OOS 노출 시간당 평균 수익과 시간봉 Sharpe가 같은 기간 BTC 무기한 B&H(펀딩 포함)보다 둘 다 낮지 않아야 한다. 하나라도 낮으면 KILL.
6. 종목 전이: 같은 규칙을 ETHUSDT에 그대로 → OOS 평균(스트레스) ≤ 0 이면 KILL.
7. 원장 대조: SMA 교차는 이미 판 우물이다. 위 1~6을 모두 통과해야만 "알려진 죽은 계열의 예외"로 인정하고, 통과해도 SURVIVE는 레드팀(T-0xx) 전까지 LIVE 근거가 아니다.

## 예상 거래 수
1h SMA5/20 교차는 대략 하루 1~2번 위로 뚫는다 → **연 200~400회**(롱만). 수수료 비중이 커서 스트레스에 민감할 것으로 본다.
