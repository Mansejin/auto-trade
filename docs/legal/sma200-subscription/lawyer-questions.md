## 1. 사실관계

1. **운영자**: 대한민국 거주 개인(사업자등록 전). 법인 없음.
2. **규칙**: "비트코인 일봉 종가가 200일 단순이동평균 위면 보유, 아니면 현금." 수십 년 된 공개 기술적 지표이며 운영자가 고안한 것이 아니다. 과거 8.5년간 전환 55회(연 약 6.5회).
3. **운영자 본인 거래**: 2026-10-08부터 운영자 본인 업비트 계정에서 이 규칙으로 자동매매 봇을 운용(현재 잔고 소액 또는 0). 데이터는 업비트 일봉 캔들(공식 Open API).
4. **검토 중인 상품**
   - (A) **무료 공개 기록**: 매일 규칙 판정(보유/현금)과 수치를 웹 페이지에 기록, 전환 시 텔레그램 단방향 채널에 1건 알림. 매수·매도 지시 문구 없음.
   - (B) **월간 리포트(유료 검토)**: 월 1회, 현재 판정·지난달 전환·누적 기록·과거 백테스트 대비 위치·한계 고지. 운영 중인 업비트 상장 알림 텔레그램 채널의 유료 구독(월 9,900~19,900원 검토)에 포함. 1:1 상담·채팅 없음, 모든 구독자에게 동일 내용.
   - (C) **셀프호스팅 봇 키트(보류)**: 사용자가 본인 PC/서버에 설치하고 **본인 거래소 API 키**로 실행하는 소프트웨어를 일회성 판매. 운영자는 사용자 키를 받지 않고 주문 실행에 관여하지 않는다. 업데이트 제공 여부 미정.
   - (D) **호스팅형(하지 않을 예정)**: 운영자 서버가 사용자 API 키를 보관하고 대신 주문. 위험 비교를 위해 질문에 포함.
   - (E) **교육**: 규칙의 원리와 한계, 백테스트·반증 방법을 다루는 글·영상·강의(유료 검토).
5. 레퍼럴·거래소 제휴·광고 수익 없음. 타인 자금을 받아 운용할 계획 없음.
