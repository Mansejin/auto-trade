# 네이버 블로그 기둥 글 개요 (SEO)

> growth-pr · 2026-10-08 · 게시는 사용자. 본문 재료는 `docs/sales/upbit-listing-alert/community-posts.md` 글 1이지만 **분위수는 채널 값(−32.9/−11.2/+12.2%)으로** 쓴다(T-025).
> 이 글은 한 번 쓰고 계속 갱신하는 글이다. 상장이 있을 때마다 "실시간 기록" 표만 고친다.

## 목표 키워드 (검색량 미확인 — 네이버 광고 키워드 도구로 사용자가 확인 후 순서 조정)

| 구분 | 키워드 |
|---|---|
| 주 | 업비트 상장 후 가격 |
| 보조 | 상장 펌핑, 업비트 상장 펌핑, 업비트 신규상장 코인, 업비트 원화마켓 상장 |
| 롱테일 | 업비트 상장 후 일주일, 상장빔 이후, 신규상장 추격매수, 업비트 상장 공지 뜨면, 해외 선물 있는 코인 업비트 상장 |
| 쓰지 않음 | "상장 펌핑 잡는 법", "상장 코인 추천", "상장 숏 수익" 같은 지시·수익형 키워드 |

## 제목 후보
1. 업비트 상장 후 가격, 1주일 뒤엔? 과거 133건 통계 (실시간 기록 중)
2. 업비트 상장 펌핑 뒤 7일, 133건을 직접 세어 봤습니다

제목에 주 키워드를 앞쪽에, 숫자 하나. 낚시성 단어(폭락 확정, 무조건)는 쓰지 않는다.

## 구조

1. **도입(3~4줄)** — "상장 공지 뜨면 몇 분 만에 수십 % 오른다. 그다음 1주일은?" 주 키워드 1회 자연스럽게.
2. **요약 박스** — 133건 / 93건 하락 / 중앙값 −11.2% / 7건 중 1건 +30% 이상(최대 +201%). 박스 안에 "개별 코인 예측 아님".
3. **무엇을 셌나** — 대상(해외 무기한이 이미 있던 원화 상장), 기간, 측정(다음 날 UTC 시가 → 7일 뒤 시가, 해외 선물 가격, 비용 제외). 왜 해외 선물 가격인지 한 줄("모든 코인을 같은 기준으로 비교하려고"). 업비트 시세 차트·캡처는 넣지 않는다(법무 쟁점 1).
4. **분포 표** — 하위10/중앙/상위10, 하락 건수, +30% 꼬리. 그래프 이미지 1장(히스토그램, 직접 만든 것).
5. **선물 상장 기간별** — 30일 이내 35건 −17.3%, 31~180일 33건 −11.7%, 180일 초과 65건 −5.5%. 소제목에 "업비트 신규상장 코인" 키워드.
6. **이 숫자로 할 수 없는 것** — 반대 포지션 기계적 운용 시 1배 최대 낙폭 −72%·최악의 달 −63%, 펀딩 비용, 2025~26 집중 79%, 약 160개 시도 중 하나라는 다중검정 한계. "상장 펌핑" 키워드는 여기서 "펌핑 뒤 숫자"라는 정보형으로만.
7. **실시간 기록 표(갱신 영역)** — `| # | 코인 | 공지일 | 7일 결과 | 과거 중앙값 대비 |`. 0건이면 "첫 알림 대기 중".
8. **채널 소개 2줄 + 링크 1개**(`blog-pillar`) — 무료, 매매 지시·레퍼럴 없음, 결과 안 지움.
9. **FAQ 3개** — "상장 코인 사면 손해인가요?"(분포일 뿐, 7건 중 1건은 +30%), "숏 치면 되나요?"(−72%, 하지 않는다), "데이터 어디서?"(해외 무기한 일봉, 기준 공개).
10. **고지** — 과거 분포, 예측 아님, 투자 권유 아님, 원금 손실 가능. AI 도움을 받았다면 표기.

## 노출 주의 (네이버 정책)
- 거래소 가입 링크·이벤트·레퍼럴 금지(미신고 사업자 홍보로 노출 제한 사례). 거래소명은 데이터 출처로만.
- 같은 내용을 여러 글로 쪼개 반복 게시하지 않는다(유사 문서). 새 글은 월간 결산만.
- 이미지 안에 키워드 숨기기·흰 글씨·태그 남발 금지.

## 후속 글 (월간 결산, M10부터)
제목 예: "업비트 상장 10월 결산: 알림 {n}건, 7일 결과 {요약}" — 기둥 글로 내부 링크, 텔레그램 링크는 `blog-monthly`.
