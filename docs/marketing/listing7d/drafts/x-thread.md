# X(트위터) 초안

> growth-pr · 2026-10-08 · 게시는 사용자. 링크는 프로필(`x-profile`)과 스레드 마지막 트윗(`x-thread`)에만. 해시태그 0~1개, 멘션·태그 없음.
> `{...}`는 그날 채널 글에서 그대로 옮긴다. 숫자를 반올림해 바꾸지 않는다.

## 0. 채널 소개 (W1, 1트윗)

```text

7일 뒤 실제 결과를 같은 번호로 남기는 텔레그램 채널을 열었습니다.

매매 지시 없음. 결과가 나빠도 안 지웁니다.
링크는 프로필에.
```

## 1. 알림 당일 (E 당일, 1트윗)

해외 무기한이 있는 알림(`alert`)에만 쓴다. 무기한이 없는 상장(`alert_no_perp`)은 집계 밖이라 트윗하지 않는다.

```text
#{alert_no} {ticker} 업비트 원화 상장 공지

과거 비슷한 상장 133건, 다음 날부터 7일 가격 변화
하위10% −32.9% / 중앙 −11.2% / 상위10% +12.2%
7건 중 1건은 7일 안에 +30% 이상 (최대 +201%)

이 코인이 어디에 떨어질지는 모릅니다. 7일 뒤 이 트윗에 결과 남깁니다.
```

## 2. 7일 결과 (R 당일, 1번 트윗 인용)

```text
#{alert_no} {ticker} 7일 결과: {ret_7d_pct}%
(과거 중앙값 −11.2% 대비 {diff_pct}%p)
7일 안 고가: {high_7d_pct}%

실시간 누적 {fwd_n}건 중 하락 {fwd_down_n}건.
30건 쌓이면 과거 분포와 비교해 공개합니다. 하락 비율 50% 미만이면 그것도 그대로.
```

## 3. 스레드: "전략 160개를 버렸다" (W3~W4)

```text
1/
자동매매 전략을 몇 년 동안 약 160개 만들어 시험했습니다.
거의 다 버렸습니다. 왜 버렸는지 정리합니다.

2/
대부분은 비트코인 가격 차트 하나에서 나온 변형이었습니다.
추세 ~60개, 평균회귀·오실레이터 ~45개, 다이버전스 단타는 변형만 ~90번.
변형을 많이 만들수록 '한 구간에서만 좋은' 전략이 우연히 나옵니다.

3/
1분~15분 단타는 수수료가 기대 움직임의 15~40%를 먹었습니다.
수수료 빼면 PF 1.13 → 넣으면 0.86~0.93.

4/
항상 켜 두는 전략은 그냥 보유를 못 이겼습니다.
5년 −14% vs 보유 +118% 같은 결과가 반복.

5/
실제 돈으로 돌리던 핵심 전략도 다시 깨 봤습니다.
실전 방식 그대로 재현하니 표본 외 +283%, 그냥 보유 +394%.
그래서 내렸습니다.

6/
지금 수익을 내세워 팔 수 있는 전략은 0개입니다.

통계로 버틴 건 하나:
"업비트 원화 상장 다음 날부터 1주일, 해외 선물 가격이 알트 지수보다 더 빠지는 경향" (133건)

7/
그런데 이걸 기계적으로 반대 포지션으로 굴리면 1배에서도 최대 낙폭 −72%.
7건 중 1건 나오는 +30% 급등이 계좌를 무너뜨립니다.
그래서 매매 상품으로 안 만들었습니다.

8/

맞든 틀리든 안 지웁니다.

배운 것: 원칙 하나 정하고, 고치지 말고, 다른 구간에서 깨 보고, 깨지면 버린다.
```

## 4. 월간 결산 (M10·M11, 1~3트윗)

```text

알림 {n}건 (해외 무기한 있음 {n_perp}, 없음 {n_noperp})
7일 결과 확정 {n_done}건: 하락 {n_down} / 상승 {n_up}
누락 {n_miss}건 (사유: {miss_reason})
누적 실시간 {fwd_n}건 / 목표 30건

좋은 달도 나쁜 달도 같은 형식으로 올립니다.
```

## 하지 말 것
- 큰 계정 글 밑에 링크 답글, 상장 코인 해시태그 몰아 달기, 같은 글 반복.
- 결과가 좋았던 건만 골라 다시 올리기(사후 하이라이트).
- "하락 확률 70%" 같은 단독 숫자. 항상 +30% 꼬리와 같이.
